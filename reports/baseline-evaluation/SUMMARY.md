# 과거 평균 기준 모델 정량 평가

## 평가 설정

- 원천 데이터: 강남구 대여소별 5분 대여·반납 데이터
- 전체 범위: 2025-10-09~2026-10-08
- 학습: 2025-10-09~2026-06-08
- 검증: 2026-06-09~2026-08-08
- 테스트: 2026-08-09~2026-10-08
- 테스트 표본: 444,009개 30분 예측 시점
- 예측 시점 간격: 30분. 서로 거의 같은 구간을 반복 평가하지 않도록 비중첩 구간을 사용했다.

학습 기간의 통계만으로 검증·테스트 기간을 예측했다. 공식 원본이 비어 있던 날짜는 수요 0으로 바꾸지 않고 제외했다.

`30분 재고 변화`는 실제 반납량에서 실제 대여량을 뺀 값이다. 수집 API의 재고 스냅숏을 직접 비교한 절대 재고 정확도와는 구분한다.

## 해석

- 요일·시간대 평균 모델은 직전 30분 반복 모델보다 테스트 대여 MAE를 13.9%, 반납 MAE를 14.5% 줄였다.
- 수요 없음 모델과 비교하면 대여 MAE는 3.0%, 반납 MAE는 4.7% 개선됐다. RMSE 개선 폭은 각각 25.2%, 26.8%로 큰 오차를 줄이는 효과가 더 뚜렷하다.
- 재고 변화 RMSE는 재고 변화 없음 모델보다 6.3% 낮지만, MAE는 8.3% 높다. 수요가 매우 희소해 작은 변화에는 0 예측이 강한 반면 현재 모델은 큰 변화의 오차를 더 잘 줄인다는 뜻이다.
- 테스트 실제 평균보다 예측 평균이 낮아 대여와 반납을 전반적으로 과소 예측한다. 최근 수요 추세, 계절, 날씨와 공휴일 변수를 다음 모델에 넣어야 할 근거가 된다.
- WAPE는 실제 수요가 0인 30분 구간이 매우 많은 자료에서 해석이 불안정하므로 MAE·RMSE와 함께 보조적으로만 사용한다.

## 산출물

- `evaluation.json`: 기간, 학습량, 커버리지, 전체 평가 결과
- `overall.csv`: 모델·분할·예측 대상별 지표
- `by_time_bucket.csv`: 출근·낮·퇴근·야간 시간대별 지표
- `by_station.csv`: 대여소별 지표

다음 평가는 현재 수집 중인 실시간 재고에서 정확히 30분 간격인 스냅숏 쌍을 만들고, `현재 재고 + 예상 반납 - 예상 대여`와 실제 30분 후 재고를 직접 비교한다.
