# 달력 변수 기반 LightGBM 1차 실험

## 목적

과거 평균 기준 모델보다 머신러닝 모델이 실제로 나은지 같은 데이터 분할과 지표로 비교했다. 첫 실험에서는 예측 시점에도 확보 가능한 변수만 사용했다.

- 대여소 ID
- 요일과 30분 시간 구간
- 월
- 연중 주기를 나타내는 값
- 주말·공휴일 여부
- 출근·퇴근 시간 구분

과거 5분 재고가 없어 학습할 수 없는 현재 재고·거치율은 넣지 않았다. 날씨와 최근 재고 변화도 다음 비교 실험으로 남겼다.

## 데이터 분할

- 학습: 2025-10-09~2026-06-08, 1,926,577건
- 검증: 2026-06-09~2026-08-08, 468,308건
- 테스트: 2026-08-09~2026-10-08, 444,009건
- 예측 대상: 향후 30분 대여량과 반납량

미래 정보가 학습에 들어가지 않도록 시간순으로 분리했다.

## 테스트 결과

| 대상 | 모델 | MAE | RMSE |
|---|---|---:|---:|
| 대여량 | 과거 평균 | **0.534** | **1.002** |
| 대여량 | LightGBM | 0.568 | 1.035 |
| 반납량 | 과거 평균 | **0.501** | **0.950** |
| 반납량 | LightGBM | 0.533 | 0.990 |
| 재고 변화 | 과거 평균 | 0.623 | **1.082** |
| 재고 변화 | LightGBM | **0.599** | 1.115 |

- LightGBM의 대여량 MAE는 과거 평균보다 약 6.4% 높았다.
- 반납량 MAE도 과거 평균보다 약 6.4% 높았다.
- 재고 변화 MAE는 약 3.9% 낮았지만 RMSE는 약 3.0% 높았다.
- 대여·반납 예측이 모두 나빠 현재 대시보드 모델을 교체할 근거가 없다.

## 해석

대여소와 시간대 변수의 중요도 합계가 대여 모델 약 80%, 반납 모델 약 81%였다. 결국 모델이 주로 학습한 내용은 기존 과거 평균과 비슷한 대여소·시간 패턴이었다. 날씨나 최근 수요처럼 날짜별 변동을 설명하는 변수가 없기 때문에 복잡한 모델을 사용해도 성능이 개선되지 않았다.

이 결과에 따라 `calendar-lightgbm-v1`은 연구용 비교 모델로만 저장하고 운영 API에는 연결하지 않는다. 다음 실험에서는 날씨를 추가한 모델을 먼저 비교하고, 실시간으로 안정적으로 확보할 수 있는 최근 재고 변화가 충분히 쌓이면 별도 모델로 추가한다.
