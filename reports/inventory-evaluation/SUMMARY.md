# 실제 재고 기반 30분 예측 평가

## 무엇을 비교했나

실시간으로 수집한 한 시점의 재고를 시작값으로 사용하고, 평균 기반 모델이 계산한 30분 후 예상 재고를 실제 30분 후 수집 재고와 비교했다.

```text
평균 모델 예상 재고 = 현재 재고 + 예상 반납량 - 예상 대여량
```

평균 모델이 실제로 도움이 되는지 확인하기 위해 `30분 뒤에도 현재 재고가 그대로다`라고 가정하는 매우 단순한 방법도 함께 평가했다.

## 사용한 데이터

- 전체 성공 수집 시점: 348개
- 정확히 30분 차이인 전체 시점 쌍: 304개
- 모델 학습 종료일 이전이라 제외한 시점 쌍: 224개
- 누수 없이 평가할 수 있는 시점 쌍: 80개
- 평가 대여소: 172곳
- 실제 재고 예측 비교: 13,760건
- 평가 시점 범위: 2026-10-13 16:25~2026-10-15 19:45(KST)

모델이 2026-10-08까지의 자료를 학습했으므로 10월 8일 이전 시점은 평가에서 제외했다. 현재 DB의 마지막 수집일은 10월 29일이지만, 10월 15일 이후에는 정확히 30분 간격으로 이어진 수집 시점이 없어 이번 평가에는 들어가지 않았다.

## 재고 수량 예측 결과

| 방법 | MAE | RMSE |
|---|---:|---:|
| 현재 재고가 유지된다고 가정 | **1.131대** | 1.870대 |
| 요일·시간대 평균 모델 | 1.138대 | **1.745대** |

- MAE는 두 방식이 거의 같고 평균 모델이 약 0.007대 높았다.
- RMSE는 평균 모델이 약 6.7% 낮았다. 평균적인 오차는 줄이지 못했지만 큰 오차를 줄이는 데에는 도움이 됐다.
- 따라서 현재 표본만으로 평균 모델이 단순 기준보다 전반적으로 우수하다고 결론 내리기는 어렵다.

## 부족·정상·과잉 분류 결과

대시보드와 같은 기준인 거치대의 20% 이하를 부족, 80% 이상을 과잉으로 분류했다.

| 방법 | 전체 정확도 | Macro F1 | 부족 Recall |
|---|---:|---:|---:|
| 현재 재고 유지 | 84.57% | 84.38% | **85.45%** |
| 요일·시간대 평균 | **84.66%** | **84.69%** | 83.02% |

- 전체 상태 정확도는 평균 모델이 0.09%p 높아 사실상 비슷했다.
- 평균 모델은 정상 상태 판별은 좋아졌지만 실제 부족 상태를 찾아내는 비율은 약 2.4%p 낮아졌다.
- 실제 재고가 0대인 품절 상황의 Recall도 평균 모델 56.43%, 현재 재고 유지 67.13%로 평균 모델이 낮았다.
- 과거 평균이 갑작스러운 수요 증가를 완만하게 만드는 특성이 있어 품절 직전의 급격한 변화를 놓칠 수 있다는 뜻이다.

## 현재 결론

과거 평균 모델은 큰 재고 오차를 줄이는 효과는 있지만, 단순히 현재 재고가 유지된다고 보는 방법보다 품절 탐지 성능이 좋지는 않았다. 따라서 평균 모델은 비교 기준으로 유지하고, 최근 5·10·30분 수요와 날씨·공휴일 등을 반영하는 모델을 추가해야 한다.

또한 이번 평가는 10월 13~15일의 짧은 기간에 집중되어 있어 최종 결론으로 사용하기 어렵다. 수집 프로그램을 연속 실행해 출근·낮·퇴근·평일·주말 자료를 충분히 확보한 뒤 동일한 평가를 다시 실행해야 한다.

## 파일

- `evaluation.json`: 평가 조건, 재고 지표, 상태 분류, 품절·만차 탐지 결과
- `overall.csv`: 전체 재고 MAE·RMSE
- `by_time_bucket.csv`: 시간대별 재고 예측 결과
- `by_station.csv`: 대여소별 재고 예측 결과
